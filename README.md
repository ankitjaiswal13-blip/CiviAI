# CiviAI

## AI-Powered Civic Issue Reporting & Routing

CiviAI is an AI-assisted civic complaint management platform designed to make reporting and handling local infrastructure issues faster and more organized.

## 🚀 Features

- Citizens can submit civic complaints
- Supports photo evidence
- AI analyzes the reported issue
- Identifies the issue category
- Assigns severity and priority
- Routes complaints to the appropriate department
- Provides a real-time complaint dashboard
- Generates a unique complaint ID
- Tracks complaint status

## 🏙️ Example Issues

- Road damage / potholes
- Garbage and waste
- Civic infrastructure problems

## 🛠️ Technology

- Python
- Flask
- HTML / CSS
- AI-based complaint analysis
- Local web dashboard
